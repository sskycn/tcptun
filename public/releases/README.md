# Releases

CLI binaries are **no longer hosted** under this path on GitHub Pages.

Download from the published npm package instead:

- Package: https://www.npmjs.com/package/tcptun
- Tarball: `https://registry.npmjs.org/tcptun/-/tcptun-<version>.tgz`
- Individual files: `https://cdn.jsdelivr.net/npm/tcptun@<version>/dist/tcptun-<platform>-<arch>[.exe]`

Example:

```text
https://cdn.jsdelivr.net/npm/tcptun@0.2.5/dist/tcptun-linux-amd64
```

Or use the one-line installer:

```bash
curl -fsSL https://tcptun.com/install.sh | sh
```
